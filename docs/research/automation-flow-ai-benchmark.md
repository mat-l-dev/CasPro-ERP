## Proveedores IA y evidencia disponible

No hay SDK/runtime CasPro que inspeccionar: AIService existente es contrato documental. Se usaron docs oficiales para evaluar capacidades, sin inferencias de una API real ni datos privados. AF-S24 [OpenAI structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [data controls](https://developers.openai.com/api/docs/guides/your-data), [pricing](https://developers.openai.com/api/docs/pricing): schema estricto en modelos admitidos, refusal/incomplete aparte; controles de datos varían por endpoint y contrato, store=false no equivale por sí mismo a zero retention. AF-S25 [Gemini structured output](https://ai.google.dev/gemini-api/docs/structured-output), [terms](https://ai.google.dev/gemini-api/terms), [pricing](https://ai.google.dev/gemini-api/docs/pricing): subset JSON Schema, valores semánticos requieren validación; servicio pagado contempla DPA y no mejora de productos con prompts, pero conserva logging limitado y no promete residencia local universal. No usar modalidad gratuita con datos empresariales por defecto.

AF-S26 [DeepSeek JSON](https://api-docs.deepseek.com/guides/json_mode/) y [pricing/modelos](https://api-docs.deepseek.com/quick_start/pricing/): JSON puede ser vacío; no equivale a schema ni verdad. AF-S27 [Qwen3-8B model card](https://huggingface.co/Qwen/Qwen3-8B) y [llama.cpp](https://github.com/ggml-org/llama.cpp): candidato local abierto, separar licencia de pesos/runtime, gramática de salida y calidad. ## Descubrimientos y puntuación

Escala de juicio de diseño1–5, no medición: V valor, F frecuencia, E reducción de error, A auditabilidad (mayor mejor); C complejidad de implementación, P coste de rendimiento, R riesgo de seguridad/privacidad, K coste de infraestructura/operación (mayor peor). Dependencias y encaje importan más que sumar cifras. NOW significa **diseño recomendado**, no aceptación independiente/implementación. Se canonizan solo dos conveniencias adicionales acotadas: vistas guardadas personales tipadas y dossier de caso; los demás NOW profundizan contratos ya exigidos o existentes.
