## Evidencia interna

El mandato CasPro y la auditoría previa de esta conversación sustentan restricciones de esta fase y contraejemplos V1. No son normas tributarias ni benchmarks. El repositorio V1 se utiliza conforme a la [política de extracción](../v1-reference/policy.md).

El mandato Foundation Amendment del 2026-09-10 define Jumpseller/Resend iniciales, emisión CPE externa, archivo en Documents y operación del primer período. S21–S25 verifican capacidades técnicas publicadas; ninguna cuenta externa fue activada o consultada con credenciales ni se leyó Wbpro para este amendment.

SUPERPROMPT 2 autoriza la [especificación del primer circuito](../specs/first-operational-circuit.md) y su publicación documental. Se reconsultaron S21–S25 y añadieron S26–S28 sobre documentación pública; el [índice oficial SUNAT](https://cpe.sunat.gob.pe/guias-y-manuales) y el manual de consulta delimitan la verificación de un CPE identificado. No se consultó Wbpro ni cuentas privadas, y ninguna validación ejecutable se declara realizada.

No se investigaron ni aprobaron aquí reglas PCGE, tasas, marcos NIIF/NPIF, régimen, reglas de emisión electrónica o tratamientos de socios. La consulta técnica S23 no determina tratamiento fiscal. Para esas afirmaciones se exige norma/fuente aplicable, vigencia, ámbito y validación profesional cuando corresponda: PENDING DOMAIN/REGULATORY VALIDATION.

Una fuente oficial de software prueba características de ese software, no una regla legal. Una fuente jurídica antigua puede seguir vigente; su edad por sí sola no la invalida. Una síntesis de IA sirve para localizar evidencia, no la reemplaza.
