# CasPro ERP

CasPro es un ERP interno diseñado primero para TILMUX S.A.C. Este repositorio contiene documentación de diseño congelada; la aceptación y sus identidades se registran en el [estado vigente](docs/review.md). La implementación depende del proceso y la autorización allí indicados; esta entrega no acredita software funcional ni producción preparada.

Empieza por el [índice y las rutas de lectura](docs/index.md). El [producto](docs/product/charter.md) explica alcance y límites; los agentes consultan [AGENTS](AGENTS.md) para seleccionar contexto local.

La [historia](docs/history/index.md) conserva el origen, las revisiones y los encargos anteriores.
